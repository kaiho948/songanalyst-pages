上傳歌曲，拆出分軌，再用繁中給 Lead／節奏結他／Bass／鼓／鍵盤／人聲可執行的編曲建議。

試聽示範 此站能做什麼
GitHub Pages 靜態示範版

這個網址是純前端（沒有伺服器）。你可以隨時打開示範曲、聽分軌、複製繁中建議。 完整上傳分析（ffmpeg／Demucs／LLM）需要本機跑 npm run dev，之後才可接 API keys。

想分析自己的歌？

在有 Node／ffmpeg 的電腦 clone 私有倉庫後： 

cd songanalyst
npm install
npm run dev -- --port 3456
# 打開 http://127.0.0.1:3456 上傳音檔

靜態 Pages 不能跑 Demucs／伺服器端分軌。上傳分析請用本機 Next app。
